# The Ties

A **9 key 3 encoder macropad** running on QMK firmware and a **RP2040 MCU**

**Features:**
- 3D printed shell
- Custom PCB
- LEDs
- All running on QMK firmware
- Change buttons, shortcuts, and LEDs from your browser on QMK
